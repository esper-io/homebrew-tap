# Esper Homebrew Tap

Install Esper CLI on macOS or Linux:

```sh
brew install esper-io/tap/espercli
```

Update an existing installation:

```sh
brew update
brew upgrade espercli
```

The formula installs the published Esper CLI binary for x86 (64-bit Intel/AMD)
or arm64. Homebrew verifies the archive checksum before installation.

See [Esper CLI](https://github.com/esper-io/esper-cli) for usage and
[releases](https://github.com/esper-io/esper-cli/releases) for downloads.
